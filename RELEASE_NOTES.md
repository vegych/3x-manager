# Релиз 3x manager v1.0.0 🎉

Первый стабильный релиз мобильного клиента **3x manager** для Android.

## 🌟 Что нового:
- **SSH-туннелирование портов**: Автоматический проброс порта для серверов 3x-ui, привязанных к `127.0.0.1` (localhost).
- **Поддержка аутентификации**: Авторизация по SSH-ключу (включая passphrases) и по паролю.
- **Встроенный веб-клиент 3x-ui**:
  - Автоматический бесшовный вход в панель без ручного ввода учетных данных.
  - Кнопка мгновенного переключения между полной версией (ПК 1280px с боковым меню и графиками) и мобильной версией.
  - Полноценная поддержка Cookie и истории навигации.
- **Управление жизненным циклом туннеля**:
  - Автоматическое выключение туннеля при закрытии приложения или смахивании из недавних задач.
  - Опция закрытия туннеля при возврате к списку серверов.
  - Фоновый режим для непрерывного подключения.
- **Скрытие IP-адресов**: Тихий переключатель в один клик в шапке экрана для защиты конфиденциальности.
- **Резервное копирование**:
  - Облачная синхронизация через Google Drive.
  - Экспорт и импорт через протокол WebDAV (Яндекс Диск, Nextcloud).
  - Локальный JSON-файл для сохранения в память или отправки через мессенджеры.
- **Material Design 3**: Выбор тем (Темная, Светлая, Системная), адаптивные компоненты и лаконичная карточка сервера с кнопкой «Открыть».
