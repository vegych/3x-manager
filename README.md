# 3x manager 🚀

**3x manager** — современное, быстрое и безопасное Android-приложение для управления серверами и веб-панелями **3x-ui** (X-UI / Xray / V2Ray) с встроенным автоматическим SSH-туннелированием.

Разработано специально для ситуаций, когда панель 3x-ui привязана к `127.0.0.1` на удаленном сервере и закрыта от внешней сети в целях безопасности. Приложение автоматически поднимает защищенный SSH-туннель (порт-форвардинг), открывает панель во встроенном оптимизированном браузере и автоматически авторизуется в ней.

---

## ✨ Ключевые возможности

### 🛡️ Безопасность и SSH-туннелирование
- **Локальный доступ (127.0.0.1)**: Подключение к панелям, не выставленным наружу в интернет.
- **Поддержка ключей и паролей**: Аутентификация по SSH Private Key (с парольной фразой или без) и по обычному паролю.
- **Интеллектуальное управление туннелем**:
  - *Закрывать при выходе из приложения* (автоматическое отключение при смахивании или закрытии).
  - *Закрывать при выходе из панели* (туннель активен только во время просмотра веб-интерфейса).
  - *Держать в фоне* (постоянный туннель для непрерывной работы).
- **Foreground Service**: Стабильная работа SSH-туннеля без выгрузки системой Android.

### 🌐 Встроенный веб-клиент 3x-ui
- **Авторизация в один клик (Auto-login)**: Автоматическая подстановка логина и пароля в форму входа 3x-ui.
- **Переключение режимов ПК / Мобильный**:
  - Полноэкранный режим ПК (1280px) с развернутым левым сайдбаром, верхним меню и графиками нагрузки.
  - Адаптивный мобильный режим для небольших экранов.
- **Умная навигация**: Поддержка системных жестов «Назад», быстрое обновление страницы и безопасное управление сессионными Cookie.

### 👁️ Приватность (Скрытие IP)
- Быстрое скрытие IP-адресов серверов в 1 клик через иконку глаза в шапке приложения (например, `194.87.***.***` для защиты от посторонних глаз и скриншотов).
- Тихое переключение без назойливых всплывающих уведомлений.

### ☁️ Резервное копирование и синхронизация
- **Google Drive**: Прямая облачная синхронизация списка серверов и настроек через Google Sign-In.
- **WebDAV**: Поддержка Яндекс Диска, Nextcloud, ownCloud или персональных хранилищ.
- **Локальный файл JSON**: Экспорт и импорт зашифрованных/структурированных бэкапов в память телефона или через системное меню «Поделиться».

### 🎨 Дизайн и эргономика
- Построен на **Jetpack Compose** и **Material Design 3**.
- Поддержка тем: **Темная**, **Светлая** и **Системная** с плавным переключением без задержек.
- Компактные карточки серверов в стиле Termius с быстрым действием **«Открыть»**.

## 🛠️ Стек технологий

- **Язык**: Kotlin 2.0+
- **UI**: Jetpack Compose, Material 3
- **Архитектура**: MVVM, Clean Architecture, StateFlow, Coroutines
- **База данных**: Room Database (SQLite) + KSP
- **SSH Туннель**: JSch (Java Secure Channel) + Java NIO TCP Forwarder
- **Сеть / Web**: Android WebView, CookieManager, Custom Viewport Engine
- **Облако**: Google Play Services Auth, Google Drive REST API, OkHttp 4 (WebDAV)

## 🚀 Сборка проекта

### Требования
- Android Studio Ladybug / Meerkat или новее
- JDK 17 или JDK 21
- Android SDK 36 (Min SDK 24 — Android 7.0+)

### Команды Gradle

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/3x-manager.git
cd 3x-manager

# Сборка отладочного APK
gradle assembleDebug

# Запуск тестов
gradle :app:testDebugUnitTest
```

Готовый APK-файл формируется по пути:
`app/build/outputs/apk/debug/app-debug.apk`
